## Repository - samarbete i utvecklingsteam 

Ett gemensamt repository används i ett utvecklingsteam för att:

* Samla all kod på ett ställe

* Man kan arbeta parallellt med varandra. Flera personer kan arbeta på olika funktioner samtidigt utan att skriva över varandras kod.

* Hantera kodkonflikter (merge conflict). Git kan merga ihop ändringar och varandras kod, men även lösa problem ifall två personer har råkat jobba på samma sak.

* Granska kod (code review). Man kan titta på varandras ändringar innan de godkänns och läggs till i huvudprojektet.
